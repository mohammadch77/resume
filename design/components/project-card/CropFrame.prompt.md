Wraps a cover/image with four corner crop-mark ticks; use only around project covers and hero frames.

```jsx
<CropFrame><CoverArt art={2} sample /></CropFrame>
```

- Ticks use `--color-line-strong`; set `--gw-crop-color: var(--color-lapis)` for hover/active.
- Don't put crop marks on buttons, forms, or text blocks.
