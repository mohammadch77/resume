A full-width band that closes a section and points to the contact form. It carries the section's only primary action, so nothing else in the same region is a primary button.

```jsx
<CtaBand
  title="پروژه‌تان را با یک گفت‌وگوی کوتاه شروع کنید"
  text="شرح کوتاهی از نیازتان کافی است؛ مسیر پیشنهادی را با هم بررسی می‌کنیم."
  ctaLabel="درخواست مشاوره رایگان"
  ctaHref="#contact"
/>
```

**You provide:** a one-line title, one sentence of text, the site-wide CTA label, an href.
**Do:** use the same label as the navbar and hero; in the light theme this is the section's one lapis block.
**Don't:** add a second button, state a promise you cannot keep (a deadline, a price, a result), put the band on a lapis ground.
