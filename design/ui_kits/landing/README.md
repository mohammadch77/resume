# Landing UI kit (reference composition)

No product UI existed when this system was built, so this is a **reference composition** of the planned single-page landing — not a recreation. It composes only design-system components (Navbar, Button, Chip, ProjectCard, CropFrame, CoverArt, Metric, Testimonial, Field, Modal, Icon) plus a few layout classes in `landing.css` (`lk-*`).

- `index.html` — interactive: anchor nav, filter chips, scroll strip with «۱ از ۴» progress, card → case-study modal, contact form with validation.
- `Landing.jsx` — sections in the order from layout rules.
- `data.js` — demo copy (all labelled «نمونه»; real copy comes from the admin panel).

Admin panel: not designed yet — intentionally omitted.
